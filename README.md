# write-article

公众号写作流程 skill，适用于 Claude Code。

帮你按照自己的风格写文章：强制检索素材库 → 写草稿 → 优化开头 → 生成标题 → 去 AI 味 → 沉淀素材。

---

## 安装

```bash
npx skills add sungwong/write-article
```

## 使用

触发方式：输入 `/write-article`，或直接说「帮我写文章」「写一篇」「写篇文章」。

第一次使用前需要先完成配置（见下方）。

---

## 配置

在 `~/.baoyu-skills/write-article/config.md` 中填入你的内容系统路径：

```markdown
# write-article 配置

## 基础路径
CONTENT_BASE: /你的路径/content-system

## 关键文件路径（相对于 CONTENT_BASE）
写作风格: 写作风格.md
开头方法论: 开头方法论.md
标题方法论: 标题方法论.md

## 素材库目录（相对于 CONTENT_BASE）
核心概念库: 素材库/核心概念库/
金句库: 素材库/金句库/金句库.md
案例库: 素材库/案例库/
已发布: 已发布/
方法论: 方法论/

## 账号草稿保存路径
账号A: 草稿/账号A/
账号B: 草稿/账号B/
日课: 草稿/日课/
```

你的内容系统目录可以自由组织，只要在配置里写清楚路径就行。

---

## 写作流程

1. **加载配置** — 读取你的内容系统路径
2. **读取风格指南** — 内化写作规范后再动笔
3. **检索素材库** — 从核心概念库、金句库、案例库里找相关内容
4. **汇报检索结果** — 列出找到的内容，等你确认要复用哪些
5. **生成草稿** — 保留你的原始细节，不压缩不总结
6. **优化开头** — 前 150 字让读者决定继续读
7. **生成标题** — 5 个候选，每个标注类型和钩子
8. **检查禁用规则** — 对照风格规范主动检查
9. **去除 AI 味** — 调用 humanizer-zh skill 跑一遍
10. **沉淀素材** — 写完后把有价值的内容存入素材库

---

## 核心原则

- **用户的原话 > AI 的总结**：你说了什么细节，全部保留
- **先检索，再创作**：跳过检索就是在浪费素材库
- **60 分就够**：快速完成，不反复打磨
- **复用优于新建**：找到相关旧内容，先问你要不要复用
